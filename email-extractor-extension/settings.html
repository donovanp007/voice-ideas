📊 Google Sheets Integration

Google Sheet ID
Enter the ID from your Google Sheet URL
How to find your Sheet ID:
Open your Google Sheet and copy the ID from the URL:
https://docs.google.com/spreadsheets/d/[SHEET_ID]/edit
Sheet Name (Tab)
Name of the tab to append data to (default: Sheet1)
Google API Key
Your Google Cloud API key with Sheets API enabled
Setup Instructions:
1. Go to Google Cloud Console
2. Create a project and enable Google Sheets API
3. Create an API key under Credentials
4. Share your Google Sheet with "Anyone with the link can edit"
